# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Dynamo, please follow responsible disclosure guidelines:

1. **Do not create a public GitHub issue.**
2. Send an email to the maintainers at `smasherthedevansh@gmail.com` describing:
   - Type of vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested mitigations or patches
3. You will receive an acknowledgment within 48 hours.
4. Maintainers will work on a fix in a private branch and publish a patched release.
